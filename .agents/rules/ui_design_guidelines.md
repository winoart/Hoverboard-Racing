# UI Design Guidelines (Hoverboard Racing)

- **UI Titles**: All UI titles (like "ROBUX SHOP", "DAILY REWARDS") must use white text (`TextColor3 = Color3.fromRGB(255, 255, 255)`) and have a thick black outline (`UIStroke` with `Color = Color3.fromRGB(0, 0, 0)` and `Thickness = 4`). Do not use plain dark text without a stroke for main UI headers.
